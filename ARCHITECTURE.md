## 🎯 球检测详细流程

```
┌─────────────────────────────────────────────────────────────┐
│                    球检测完整流程                            │
└─────────────────────────────────────────────────────────────┘

输入帧 (800x600 ROI区域)
       │
       ↓
┌──────────────────────────────────┐
│  1. HSV颜色空间转换               │
│  BGR → HSV                       │
│  cv2.cvtColor(frame, BGR2HSV)    │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  2. 颜色范围过滤                  │
│  lower = [20, 50, 55]            │
│  upper = [70, 255, 255]          │
│  mask = cv2.inRange(hsv, ...)    │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  3. 形态学操作去噪                │
│  kernel = MORPH_ELLIPSE(3,3)     │
│  MORPH_CLOSE → MORPH_OPEN        │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  4. Hough圆检测                   │
│  cv2.HoughCircles(               │
│    dp=1, minDist=36,             │
│    param1=35, param2=6,          │
│    minRadius=18, maxRadius=45    │
│  )                               │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  候选球列表                       │
│  [(x1,y1,r1), (x2,y2,r2), ...]   │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  5. 质量评估                      │
│  for each (x,y,r):               │
│    • 提取球区域                   │
│    • 计算HSV均值和标准差          │
│    • 颜色一致性评分               │
│    • 周围环境对比度               │
│    quality = weighted_score      │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  6. 圆度检查                      │
│  for each (x,y,r):               │
│    • 提取边缘                     │
│    • 计算到中心距离               │
│    • 标准差 / 平均距离            │
│    circularity = 1 - normalized  │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  7. 过滤低质量候选                │
│  filtered = []                   │
│  for ball in candidates:         │
│    if quality > 0.45 &&          │
│       circularity > 0.56:        │
│      filtered.append(ball)       │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  8. 边界和屏蔽区域检查            │
│  • 检查是否在boundary内           │
│  • 检查是否在mask_zones外         │
│  • 检查是否在ROI内                │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  9. 静态球过滤                    │
│  for each ball:                  │
│    • 查找历史记录                 │
│    • 计算移动距离                 │
│    • 判断是否静止                 │
│    if movement < 6px for 10f:    │
│      mark as static              │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  10. 轨迹追踪                     │
│  • 最近邻匹配 (距离 < 52px)       │
│  • 更新轨迹历史                   │
│  • 插值缺失点                     │
│  • 移除离群值                     │
└──────┬───────────────────────────┘
       │
       ↓
┌──────────────────────────────────┐
│  11. 单球选择                     │
│  if multiple candidates:         │
│    • 优先选择轨迹连续的球         │
│    • 其次选择质量最高的球         │
│    • 最后选择最大的球             │
└──────┬───────────────────────────┘
       │
       ↓
输出: (x, y) 或 None
```

## 🔍 精彩瞬间检测算法

```
┌─────────────────────────────────────────────────────────────┐
│              精彩瞬间检测 - 局部最小距离算法                  │
└─────────────────────────────────────────────────────────────┘

时间轴: t-2    t-1    t(当前)   t+1    t+2
       │      │      │         │      │
距离:  100px  80px   75px      82px   95px
       │      │      │         │      │
       │      │      ↓         │      │
       │      │   局部最小      │      │
       │      │   (击球瞬间)    │      │
       │      │      │         │      │

检测条件:
1. prev_dist (75px) ≤ prev2_dist (80px)  ✓ 距离在下降
2. dist (82px) ≥ prev_dist (75px)        ✓ 距离开始回升
3. prev_dist ≤ threshold (150px)         ✓ 在阈值内
4. frame_num - last_hit ≥ cooldown (12)  ✓ 冷却时间足够

高级抑制条件:
5. consecutive_inside ≥ min_inside (1)   ✓ 停留帧数足够
6. prev_dist ≤ threshold * ratio (2.0)   ✓ 相对距离足够小
7. exit_increase ≥ min_exit (0px)        ✓ 离开增加足够
8. enter_decrease ≥ min_enter (0px)      ✓ 进入减少足够
9. ball_speed ≥ min_speed (0px/f)        ✓ 球速足够快

触发动作:
→ 保存前5帧 (t-5 到 t-1)
→ 保存中心帧 (t-1, 局部最小距离帧)
→ 等待后15帧 (t 到 t+14)
→ 生成短视频 (21帧, 约0.84秒 @ 25fps)
→ 保存中心帧图片 (带标注)
→ 生成分析JSON
→ 生成阶段截图 (5张)
```
