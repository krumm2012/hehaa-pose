## 一、 评分体系设计理念与目标

在网球竞技与训练中，单拍挥拍质量绝非单纯由球速（Racket Speed）或球落点决定，而是受动力学链（Kinematic Chain：**下肢蹬地 ➔ 髋骨转动 ➔ 躯干与肩部旋转 ➔ 手臂舒展延伸 ➔ 拍头鞭打释放**）各环节协同决定的。

算法 2.0 依托**正面主视口 + 镜面背面视口**的双机位融合姿态与球/拍统一感知，建立了客观、量化、物理可解释的**单拍综合技术评分体系（Swing Quality Score）**：
1. **满分标杆（100 分制）**：将传统主观“感觉”转化为确定性的生物力学数学函数。
2. **多维短板可追踪（Sub-scores）**：提供转肩、引拍、伸展、挥速、蹬地 5 项分项得分，清晰指出丢分点。
3. **“测-评-纠”闭环（Coach Linking）**：分项短板直接联动智能教练规则，输出精准在 15 汉字以内的靶向纠错建议。

## 二、 综合评分公式与权重模型

单拍综合技术评分采用加权线性模型，综合 5 大生物力学核心维度：

$$\text{Total Score} = 0.25 \times S_{\text{turn}} + 0.25 \times S_{\text{takeback}} + 0.20 \times S_{\text{arm}} + 0.15 \times S_{\text{speed}} + 0.15 \times S_{\text{leg\_drive}}$$

结果四舍五入保留 **1 位小数**。

### 维度权重分布矩阵

| 评估维度 | 评估目标 | 核心力学指标 | 权重 | 满分基准 ($100$ 分) | 归零/底线基准 ($0$ 分) |
| :--- | :--- | :--- | :---: | :---: | :---: |
| **1. 躯干转动蓄力** | 躯干线旋转深度 | 抗侧身塌陷转肩角 (`robust_shoulder_turn_deg`) | **25%** | $\ge 42.0^\circ$ | $\le 0.0^\circ$ |
| **2. 后背引拍深度** | 拍头环形蓄力路径 | 后背引拍深度比率 (`takeback_depth_ratio`) | **25%** | $\ge 1.50$ | $\le 0.0$ |
| **3. 触球结构舒展** | 击球点空间杠杆 | 肘关节伸展角度 (`arm_extension_deg`) | **20%** | $\ge 165.0^\circ$ | $\le 90.0^\circ$ |
| **4. 拍头爆发挥速** | 拍头物理鞭打速度 | 拍头动力学峰值挥速 (`racket_speed`) | **15%** | $\ge 85.0\text{ km/h}$ | $0.0\text{ km/h}$ |
| **5. 下肢垂直蹬地** | 重心下潜与垂直送髋 | 质心垂直蹬地比率 (`leg_drive_ratio`) | **15%** | $\ge 0.22$ | $\le 0.0$ |

## 三、 五大生物力学分项计算规则详解

### 1. 转肩蓄力得分 ($S_{\text{turn}}$，权重 25%)

* **物理意义**：衡量引拍准备至击球阶段，上躯干相对下肢和球网的旋转扭矩。
* **计算公式**：
  $$S_{\text{turn}} = 100.0 \times \min\left(1.0, \max\left(0.0, \frac{\text{turn\_deg}}{42.0}\right)\right)$$
* **基准依据**：
  - 现代职业正手在击球准备期转肩角普遍在 $40^\circ \sim 50^\circ$。
  - 达到 $42^\circ$ 即视为身体蓄力充分满分；若转肩不足 $20^\circ$，身体呈“正面僵直推击”，此项得分将低于 $47$ 分。

### 2. 后背引拍深度得分 ($S_{\text{takeback}}$，权重 25%)

* **物理意义**：通过背面机位，测量击球手腕在后背空间相对脊柱中线的水平离轴最大距离与肩宽的比例。
* **计算公式**：
  $$S_{\text{takeback}} = 100.0 \times \min\left(1.0, \max\left(0.0, \frac{\text{takeback\_ratio}}{1.50}\right)\right)$$
* **基准依据**：
  - 完整的现代网球环形引拍（Loop / "C" Takeback）在蓄力顶点时，拍头与手腕应深度拉至后背纵深，通常达身体解剖肩宽的 $1.4 \sim 1.8$ 倍。
  - 设定 $1.50$ 为满分基准；若引拍过浅（手腕未拉过脊柱侧线，比率 $<0.5$），得分极低。

### 3. 手臂舒展延伸得分 ($S_{\text{arm}}$，权重 20%)

* **物理意义**：击球瞬间（Contact Point）肘关节的张角，衡量击球点是否具有理想的前迎空间。
* **计算公式**：
  $$S_{\text{arm}} = 100.0 \times \min\left(1.0, \max\left(0.0, \frac{\text{arm\_deg} - 90.0}{75.0}\right)\right)$$
* **基准依据**：
  - **$\le 90^\circ$ 扣为 0 分**：表明击球点严重贴身被挤压，或是恐慌性缩手推球。
  - **$\ge 165^\circ$（即 $90 + 75$）获得 100 分**：兼顾现代直臂正手（Straight-arm，如费德勒/纳达尔约 $165^\circ \sim 175^\circ$）与双弯曲正手（Double-bend，如德约科维奇约 $145^\circ \sim 160^\circ$ 在满分区间附近）。

### 4. 拍头爆发挥速得分 ($S_{\text{speed}}$，权重 15%)

* **物理意义**：由击球窗口前后拍头在 2.5K 空间中的移动矢量结合人体肩宽绝对标尺推算的瞬时线速度。
* **计算公式**：
  $$S_{\text{speed}} = 100.0 \times \min\left(1.0, \max\left(0.0, \frac{\text{speed\_km/h}}{85.0}\right)\right)$$
  *(注：若全视频未检出球拍或遮挡严重，自动采用中位保底值 $75.0$ 分)*
* **基准依据**：
  - 业余进阶球友（NTRP 3.5~4.5）良好击球的拍头速度通常在 $60 \sim 80\text{ km/h}$，半职业及职业级突破 $90 \sim 110\text{ km/h}$。
  - 设定 $85.0\text{ km/h}$ 为业余高阶满分基准线。

### 5. 下肢垂直蹬地发力得分 ($S_{\text{leg\_drive}}$，权重 15%)

* **物理意义**：准备期身体重心（左右髋关节中点）下潜最低点，至击球瞬间向上蹬伸抬起高度占身体解剖肩宽的比例。
* **计算公式**：
  $$S_{\text{leg\_drive}} = 100.0 \times \min\left(1.0, \max\left(0.0, \frac{\text{drive\_ratio}}{0.22}\right)\right)$$
* **基准依据**：
  - 充分屈膝蓄力并借助地面反作用力（Ground Reaction Force）送髋蹬地，髋部抬升通常达到解剖肩宽的 $20\% \sim 25\%$。
  - 设定 $0.22$（22% 抬升）为满分基准；若全程站桩平移，蹬地比 $< 0.05$，该项得分直接跌至 $20$ 分以下。

## 四、 四级技术评级划分（Performance Grades）

根据最终加权综合得分，评定四级段位技术标签：

```
100 ──────────┐
              │  🌟 PRO (职业级)            [88.0 ~ 100.0 分]
 88 ──────────┼────────────────────────────
              │  🥇 ADVANCED (高级进阶)      [75.0 ~ 87.9 分]
 75 ──────────┼────────────────────────────
              │  🥈 INTERMEDIATE (中级进阶)   [60.0 ~ 74.9 分]
 60 ──────────┼────────────────────────────
              │  🥉 DEVELOPING (基础强化)    [0.0 ~ 59.9 分]
  0 ──────────┘
```

* **🌟 PRO（职业/专业级，$\ge 88.0$ 分）**：
  - 动作极具爆发力与连贯性。转肩 $\ge 40^\circ$、引拍深且大、击球点舒展充分、挥速 $>80\text{ km/h}$ 并伴随明显的垂直蹬地发力。
* **🥇 ADVANCED（高级进阶，`75.0 ~ 87.9` 分）**：
  - 具备成熟正规的现代网球动力链框架，引拍与随挥完整，各项力学指标均衡无明显短板。
* **🥈 INTERMEDIATE（中级进阶，`60.0 ~ 74.9` 分）**：
  - 业余俱乐部主流水平。已有稳定击球形态，但常存在特定技术代偿（例如“仅靠手臂发力无下肢蹬地”或“击球点靠后手臂不够伸展”）。
* **🥉 DEVELOPING（基础强化，`< 60.0` 分）**：
  - 初学或发力模式错误阶段。存在严重的动作结构性缺陷（如屈臂挤球、僵直推球、无身体旋转蓄力）。

## 五、 实战案例得分拆解（以基准视频 40.26 为例）

### 案例 1：中级典型击球（击球 #1，帧 36）
* **综合得分**：**`67.8` 分**
* **技术评级**：**`INTERMEDIATE`**
* **分项得分详单**：
  - 转肩角 $28.9^\circ$ $\to$ **$68.7$ 分**（尚有转肩蓄力空间）
  - 引拍深度比 $1.59$ $\to$ **$100.0$ 分**（后背深度引拍充分）
  - 手臂伸展角 $142.7^\circ$ $\to$ **$70.3$ 分**（中等舒展）
  - 拍头挥速 $57.4\text{ km/h}$ $\to$ **$67.5$ 分**
  - 垂直蹬地比 $0.04$ $\to$ **$18.2$ 分** ⚠️ **（主要扣分点：站桩击球，几乎无下肢蹬地）**
* **加权复核**：
  $$\text{Total} = 0.25 \times 68.7 + 0.25 \times 100.0 + 0.20 \times 70.3 + 0.15 \times 67.5 + 0.15 \times 18.2 = 67.8\text{ 分}$$

## 六、 评分短板与智能教练纠错联动机制

当某一维度的子项得分过低时，系统确定性激活对应级别的智能教练纠错建议（每条 $\le 15$ 汉字），拒绝盲目泛化：

| 触发子项低分阈值 | 触发条件 | 教练建议编码 | 智能教练纠错播报语 (≤15字) |
| :--- | :--- | :--- | :--- |
| **下肢蹬地** $S_{\text{leg\_drive}} < 40$ | $\text{drive\_ratio} < 0.08$ | `limited_knee_flexion` | `准备时适当降低重心` |
| **手臂舒展** $S_{\text{arm}} < 75$ | $\text{arm\_deg} < 145^\circ$ | `limited_arm_extension` | `挥拍时手臂再舒展` |
| **转肩蓄力** $S_{\text{turn}} < 70$ | $\text{turn\_deg} < 30^\circ$ | `limited_shoulder_turn` | `提前转肩充分引拍` |
| **引拍深度** $S_{\text{takeback}} < 65$ | $\text{takeback\_ratio} < 1.0$ | `limited_takeback_depth` | `后背引拍拉开拍头` |
| **空挥/未触球** | `is_shadow_swing = True` | `SHADOW_SWING` | `未触及球，注意盯球击球点` |

## 七、 维护与拓展约定
