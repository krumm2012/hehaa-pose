# 动力链准确性验证路线：Tennis Analyzer × Tennis-Vision

2026-10-04；基于当前工作区、两项目源码、历史实验记录与用户指定会话的回顾。以下迭代是建议实施方案，不代表已经通过验收。

结论：现有工程已能定位挥拍、保存证据、比较前后视角并辅助教练复核，但尚未验证骨盆—躯干—球拍的真实三维时序。优先顺序应是 **测量定义 → 视频时间轴 → 实测几何 → 独立参考 → 角速度/峰值评估 → 置信度校准 → 教练结论**。SAM3D 模型、镜面拟合与更平滑的播放都不能替代这条验证链。

## 2. 当前最需要修正的测量问题

**时间语义。** [main_pipe.py](/Users/krum5539/Documents/tennis_analyzer/main_pipe.py:588) 的 `captured_at_unix_ns` 是 `cap.read()` 后的 `time.time_ns()`；[kinematic_sequence.py](/Users/krum5539/Documents/tennis_analyzer/kinematic_sequence.py:186) 优先把它当物理时间。视频文件的解码吞吐与背压可以改变这个间隔。`frame_processor.py` 的 `frame_id/fps` 则是假设等间隔。两者都不是原始变帧率视频的逐帧曝光时间。此前新增分析已明确未验证，但时间优先级仍需在下一轮修正。直播读帧时钟也只有接收时间语义，不能自动等同传感器曝光。

**空间语义。** [dual_view_biomechanics.py](/Users/krum5539/Documents/tennis_analyzer/dual_view_biomechanics.py:390) 的 `atan2(back_width, front_width)` 没有相机标定或透视反演，是宽度比代理。作为反例，两个相反方向的正交投影视角可同时得到与 `|cos(theta)|` 成比例的宽度，比值恒定而人体在转动；该公式不能一般地恢复真实转肩角。肩髋分离角目前也来自图像中的两条线。前后视角二维角速度即使都正确，也可能因投影不同而不相关，因此二维曲线一致仅是保守筛查。

**“肩”和“拍”的定义。** 肩关节点连线方向不是肩关节内旋，也不自动等于胸廓轴向转动；左右髋关节中心连线也不等于标准骨盆标记坐标系。拍框中心速度不是拍头速度；拍柄与手部固定关系也不是拍头真实轨迹。必须先规定指标，否则不同项目看似同名的数值不能比较。

**置信度语义。** 当前二维 `evidence_confidence` 是覆盖、关键点质量与曲线一致性的启发式分数；25 fps 时峰值跨视角容差约为 80 ms，远不是十几毫秒时序准确性的证明。`coach_eligible=false` 应继续保留。没有独立真值时不输出“正确概率”。

**解释语义。** 本轮范围是运动学时序。仅由运动视频不能证明力、关节力矩、功率或能量由腿传到拍；如需这类动力学判断，另需力学测量与有效模型。负峰值间隔目前表示所定义曲线的峰值先后，不直接等于动作不连贯。

## 3. 已有实验值得借鉴的证据

### 3.1 本次九段数据复算

以原生 `reconstruction.npz` 中真人/镜中独立 SAM3D 关节、各片段自己的镜面参数计算；验证源视频、模型、元数据、几何 SHA256 一致。使用 MHR 肩 5/6、髋 9/10，按反射矩阵恢复方向，在同一帧比较，不平移曲线；不跨缺失帧求速度。

九段共 **2242 帧，2159 帧具有有效镜中模型**。各段髋轴方向差中位数 **6.36–12.21°**，肩轴 **7.40–11.13°**；同帧三维方向变化速度相关系数髋 **0.680–0.869**、肩 **0.794–0.918**。九段都标记 `measured_camera=false`。这些数字是模型一致性试验，不是相对于真实动作的角度误差、准确率或轴向速度精度。

数据：[九段汇总 JSON](/Users/krum5539/Documents/tennis_analyzer/data/analysis_results/kinematic_validation/nine_clips_iteration_review_20261004/pilot_summary.json)；算法：[核验脚本](/Users/krum5539/Documents/tennis_analyzer/scripts/validate_kinematic_3d_evidence.py)。九段来自同一组拍摄，适合开发与反例回归，不能作为九个独立球员/机位的泛化测试。

### 3.2 Tennis-Vision 历史教训

原片与标准化视频帧数、时间轴不一致；按平均 fps 映射可能把相邻帧当同一帧。镜面拟合训练残差变好但保留样本变差时应拒绝。自己反投影再投影几乎零误差仍不证明真实几何。固定 9cm 是指定握点，不是自动测距真值；八段应用中强观测仅约 19%，平滑/约束帧不能升级为拍头测量真值。详细出处与数值见 [Tennis-Vision 证据回顾](TENNIS_VISION_KINETIC_EVIDENCE_REVIEW.md)。

## 4. 逐轮迭代与验收

| 顺序 | 要做的事 | 可复核产物 | 进入下一轮的条件 |
| --- | --- | --- | --- |
| 0：冻结定义与基线 | 先只验证骨盆轴向转动、躯干轴向转动及两者峰值间隔；记录击球类型、惯用手、方向；拍头单列后续指标 | 指标协议、当前模型/参数/数据哈希、九段失败样本清单 | 指标双方采用同一坐标/符号/时间定义；未知值无补全 |
| 1：时间轴 | 保留源 PTS、原帧ID、标准化帧映射、接收/处理时间；文件分析不使用处理墙钟；直播记录时钟来源与不确定度 | 帧映射表、重复/丢帧/VFR 报告、源与标准化回放对照 | 改变解码速度/背压不改变物理峰值；重复帧不被视为新增曝光；不确定时间段拒绝判序 |
| 2：镜面几何 | 实测 K/畸变、地面坐标、镜面平面；在身体所在深度范围拍已知位置/长度的标定物 | 标定版本与独立空间位置误差，留出姿态/位置残差 | 留出空间误差合格；不使用待验证髋肩曲线反向调镜面来提高一致性 |
| 3：三维基线 | 用原始前后 2D 点＋已标定真实/虚拟相机三角化，保留重投影、深度、视线夹角与协方差；另跑 SAM3D 比较 | 每帧 `observed_2d / triangulated_3d / model_3d / imputed` 分层轨迹 | 能分辨左右语义、镜像恢复和几何退化；弱夹角/遮挡不可借先验提高测量置信度 |
| 4：独立参考 | 同一次挥拍同步高速参考/标记动作捕捉，单独标注触球区间；参考质量也需记录 | 独立坐标/轨迹/标注与同步文件；开发/校准/测试整组切分 | 有参考的空间/时间不确定度，确认双方解剖定义可对应；教练不看模型先标事件 |
| 5：角速度与峰值 | 按世界坐标和身体段定义算轴向运动；确定符号、窗口、滤波与多峰规则；保留角度/角速度全曲线及峰值区间 | 每拍误差表、曲线、误差区间、失败案例 | 位置→角度→速度→峰值分层通过；窗口与滤波轻微改变时结论稳定；区间重叠判不确定 |
| 6：消融与置信度 | 比较 front-only、back-only、二维筛查、标定三角化、独立 SAM3D、几何＋模型融合；在校准集拟合误差概率 | 保留集误差与覆盖率、置信度校准、分条件风险 | 独立测试上双视角确有增益；同时报告拒绝率与已接受错误率；调参后重评未见测试集 |
| 7：教学结论 | 在时序测量合格子集上，盲法双教练评价身体协调；与拍速/有效回球等结果对照 | 测量值、教练判断、训练建议分开存储；分歧复核 | 教学结论一致性和重复性单独达标，才能逐项开放自动建议 |

镜面双视角来自同一传感器，可减少跨设备时间同步负担；仍须审核滚动快门、源曝光、图像裁剪与派生帧映射。镜面距离平面反射的几何应由标定确定，不能简单将两个 ROI 当已知立体相机。

## 5. 验证协议与指标

### 最小实验

先用九段建立开发反例集，补原始 PTS 映射和独立触球区间，不强行生成它们缺失的三维真值。随后用一个已知几何的旋转标定物验证坐标、反射、符号和时序，再采同一球员同一机位的同步真实挥拍作为小型可行性试验。标定物验证仪器/算法，不能代替人体关节验证。

新采集建议真实 200–240 Hz 高速参考或足够高频的独立动作捕捉，以研究十几毫秒的峰值差；验收实际曝光时间、快门和同步误差，插帧或把容器设成 50 fps 不增加观测。参考如果只有高速像素视频，只能为触球时刻/可见轨迹提供参考；没有独立标定和三维重建时，仍不能作为完整三维运动真值。

可先规划 6 位球员 × 每位约 30 拍的探索采样（建议量，不是证明充分性的统计样本量），覆盖遮挡/侧身、两种击球方向与机位变化；正式样本量按先导误差和使用目标确定。跨球员、采集日和机位划分开发、校准及最终测试集，同次挥拍的所有帧和视角必须处于同一分组；同一原片拆出的九段不能随机按帧分到训练/测试。

先以正手建立测量协议；单反、双反与发球随后分别验证，不把正手的“理想顺序”直接套给其它动作或站姿。

### 每层必须报告的量

- **事件**：完整时间轴的挥拍 Precision/Recall/F1，触球时刻误差及参考标注区间。复用 `swing_evaluation.py`，但新增动力链 evaluator，不能以事件类型准确率代替峰值精度。
- **空间**：原始观测误差、独立三维标记/段姿态误差，按遮挡与视线夹角分层。训练重投影和留出重投影各自统计；三维误差不能由像素残差直接换算。
- **角度/速度**：轴向角度环形误差、角速度曲线 RMSE/偏差及协议规定的符号；与参考同时间点比较。为提高相关而任意平移时间会掩盖峰值延迟，禁止用于正式评估。
- **峰值**：骨盆峰、躯干峰、拍头峰分别报告时间 MAE、偏差、P95；`delta = t_trunk_peak - t_pelvis_peak` 的误差和区间单列；多峰/平峰保留歧义。
- **判序**：只有参考峰值区间可区分时才统计正序/逆序；报告参考本身不确定的比例、模型不确定比例，以及模型对参考不确定样本强行给结论的数量。
- **置信度**：记录“在指定误差容限内正确”的校准曲线、Brier/ECE 或区间覆盖率、置信度阈值对应的接受覆盖率与错误率；按球员/机位/遮挡分组，区间统计按挥拍/球员聚类，不能把邻近帧当独立样本。
- **实时性**：延迟、掉帧与吞吐另列；实时因果滤波与离线零相位滤波分别对参考验证，不能将后者的精度归给前者。

### 建议工程目标，必须先导校准

先把轴向角度 MAE 5°、单段峰值时间 MAE 10 ms/P95 20 ms 作为探索目标，不是网球标准、也不是当前已达结果；应结合参考不确定度调整。达到这组总体误差目标也不能保证每次 18 ms 的正负顺序都可分辨。

单拍判序的必要门槛应是 **峰值差区间完全位于零的一侧**；峰值区间须经保留集覆盖率校准，不能只用一帧宽度冒充统计置信区间。若目标是自动指导，再预先规定可接受的错判上限和最低覆盖率，独立测试报告其区间；不能只挑最容易的少数拍宣称高准确率。

## 6. 两项目如何协作

**Tennis Analyzer** 保持轻量实时感知、独立原始双视角帧记录、挥拍/触球候选、证据回放与低延迟展示。第一轮应修改 reader/FrameRecord 的源时间契约、`kinematic_sequence.py` 时间选择和相关测试。

**Tennis-Vision** 作为离线审计工作台，提供镜面空间标定、三维重建对照、轨迹/峰值曲线、人工参考标注与失败样本复核。沿用原始模型及历史验收文件，不为达到动力链一致性重写历史拟合。

**共同协议** 用版本化 sidecar 连接两项目，而不是把 SAM3D 放进实时逐帧路径：视频内容哈希、源 PTS/派生帧映射、校准版本、惯用手、动作类型、坐标/关节定义、测量/补全来源、单位、模型/滤波版本、参考身份及用途、峰值区间、判序与拒绝原因、验证状态。依照 [ADR 0002](adr/0002-replayable-session-evidence-bundle.md) 保存新一轮证据与哈希。训练条件用于分层，设备积分不转换成动力链真值。

## 7. 原始研究如何使用

[Landlinger 等（2010）](https://pmc.ncbi.nlm.nih.gov/articles/PMC3761808/) 使用 8 台相机、400 Hz Vicon、身体与球拍标记以及明确的全局坐标、前挥窗口与触球定义。研究中的骨盆/躯干峰值均值相差约 18 ms，说明本项目应认真处理采样及滤波；这是特定男性正手样本结果，不能作为业余选手或所有动作的合格阈值。论文也讨论采样率、滤波对时间—速度曲线的影响。

[ISB 关节坐标定义 Part I](https://pubmed.ncbi.nlm.nih.gov/11934426/) 与 [Part II](https://pubmed.ncbi.nlm.nih.gov/15844264/) 可用于设计解剖坐标定义。是否能按这些定义测量取决于实际可观测的标记和关节，不能仅把模型的“肩/髋”标签改名就声称符合标准。

本轮新增的是算法回顾、九段模型一致性复算和验证路线；没有执行上述硬件标定、独立三维采集、置信度训练或自动教练上线。
