# 事件媒体时间与自动建议资格

2026-10-05。实现定义：`event_source_timing.py`、`coach_rule_contract.py`。
这是源时间消费者与教学资格的工程修正，不代表曝光、阶段边界或技术准确性验证通过。

## 时间字段

事件新增 `phase_timing`，Coach 数据集使用 `coach_dataset_v1.3`，记录
`timing_policy=event_phase_media_time_v1`。不从声明 FPS、接收墙钟或兼容
`timestamp` 换算测量秒数。原记录和模型阶段标签不回写。

| 字段 | 操作定义 | 有效条件与限制 |
| --- | --- | --- |
| duration_seconds | PTS(end) − PTS(start) | 两端都在原始记录中；不增加末帧尾部时长 |
| start_to_contact_seconds | PTS(contact) − PTS(start) | 触球是事件候选锚点，不能当独立确认 |
| contact_to_end_seconds | PTS(end) − PTS(contact) | 结束是模型事件边界 |
| peak_to_contact_offset_seconds | PTS(contact) − PTS(peak) | 保留符号；负值只表示候选触球早于该运动峰 |
| phase_durations_seconds | 对每个模型标签求 Σ(PTS(i+1) − PTS(i)) | 左样本标签支持下一已观测区间；不外推最后一帧 |
| recovery_time_seconds | 上表中 ready 标签的覆盖，缺少则 null | 历史字段兼容，不能解释为真实回位完成时间 |
| preparation_time_fraction | start_to_contact_seconds / duration_seconds | 仅为候选锚点时间比例，不能分类及时或迟缓 |
| tempo_consistency | min(before,after) / max(before,after) | 兼容字段，仅为触球前后时间平衡量，不能评价技术节奏 |

源帧身份必须是非负整数；开始、触球、峰、结束都在事件内且存在。
区间内使用 `tennis.source-time.v1`、`video_file`、`media_pts`、`reported`，
身份与记录帧号一致，时间有限、非负且严格递增。零时刻有效。时间缺失、
重复、倒退、混用来源、估计时钟或旧格式会返回具体原因和 null。

存在源帧缺口时可以保留已知锚点的媒体经过时间，但不跨缺口积分模型标签。
标签缺失、重复或属于另一事件时不生成阶段时间。合格阶段时间的总和等于
该事件媒体经过时间；它不是观测帧数/FPS，也不证明实际动作阶段边界。

## 原视频回放

独立报告使用已记录源帧ID→媒体PTS对照。播放时二分查找当前媒体时间对应
的已知源帧，定位时只查对应PTS；不按平均FPS推算变帧率视频的位置。
未知帧号无法准确定位；缺少合格时间对照时禁用帧滑块，原生视频播放仍可用。
定位使用已知PTS区间内最多2微秒的偏移，避免媒体API截断造成前一帧显示；
它不增加原视频时间分辨率，最终解码曝光仍需单独核验。

该对照只允许用于声明的原始输入路径，包括会话 `source`，不能直接应用到
重新编码的标注视频、挥拍片段或不同视频。路径相同只是声明的来源绑定，
不是独立字节身份验证；正式关联需证据包SHA与派生映射。源PTS也不证明浏览器
实际解码曝光、滚动快门或转码前的曝光。原片与249帧派生副本映射仍待验证。

实时报告与独立报告共用媒体时长说明，明确模型标签覆盖、缺失原因和评分禁用。
实时视频片段的自身编码时间另行使用，不能套原视频PTS。

报告不再从其他视频目录或全局scratch按相似帧号猜定格图。新截帧保留实际
源帧ID，临近回退帧不标成触球帧；旧本地定格明确来源未核验。
离线分析/重放明确执行范围，不能把重放时刻减历史接收时刻作为实时延迟。

## 自动技术建议

`automatic_coach_v2_validated_rules_only` 的批准规则集合当前为空。规则批准
来自代码内登记的独立验证结果；外部 `coach_eligible`、`accuracy_validated`、
高模型分数、历史子分或人工评分，均不能单独批准自动规则。

本地Coach和DeepSeek共用该资格。捕获和复核提示继续可用；原始二维指标、
帧计数与确认的人工评分继续保存。当前自动准备/随挥/拍速子分为空，删除短
阶段帧数和低像素拍速的技术诊断；像面肩线变化不再派生转肩技术等级。
DeepSeek不能因某个body字段非空而自动生成“保持动作连贯”等正向技术结论。
语言模型confidence仍不是经校准正确率；网络旁路保持异步。

有些旧阈值候选保留为规则机制，代码批准前不会执行。测试中明确标为合成批准
的用例只检查排序、去重和拍摄优先级，不是生产规则独立验证证据。

## 仍未闭环

- 分段、motion_features、实时帧窗口及其他旧消费者还需源时间审核；传统角度
  窗口仍按帧ID，未宣称所有窗口统一。
- 像素运动、插值与归一化误差仍需独立定位参考；不开放真实速度或力量结论。
- 真正阶段时长、触球、三维时序和技术建议需要独立标签、同步参考及双教练验证。
- 本修正不提供RTSP设备时钟或曝光标定，不改变Vision历史拟合。
