# 人工 Coach 审核 V3

业务版本：`human_coach_review_v3`，2026-10-18。沿用控制台、事件卡片、逐帧证据与原提交 API；标注 JSON 仍为 `swing_manual_annotations_v2`，新增字段向后兼容。

## 审核顺序

1. 完整查看原视频，确认事件是否存在、是否重复或漏检，修正边界。`valid_hit` 表示有效事件，`needs_review` 表示事件尚待复核；`count_correct` 记录计数意见，实际排除重复项仍需取消其有效事件勾选。
2. 选择动作类型。有效事件可以是 `Unclear`，不因类型不明判为误报。类型匹配仅使用双方类型均明确的配对，并报告可比数。
3. 修正触球候选源帧号；单独选择 `contact_review`：未审核、已确认、看不清、不适用。旧帧号不推断为人工确认。候选帧对齐与已确认触球帧容差匹配分别统计。
4. 审核系统建议：证据支持、不采纳、证据不足或未审核。提交判断必须填写审核人、可见事实、证据帧及视角；本次教练建议可单独记录。
5. 人工五维评分复用 `practice_policy.json` 的 1–5 分锚点。看不清留空，允许草稿；确认总分需五项完整、事件复核完成、触球确认和教练意见审核。自动雷达不能填充人工分。
6. 点击“保存并评估当前审核”持久化，下载 JSON 备份。浏览器输入先存草稿；修改后旧对照提示待重算，页面重开优先保留浏览器草稿，没有草稿时恢复会话提交记录。

## 结果的含义

- 事件对照完成不代表触球、教练审核或五维评分全部完成。分开显示完成数量。
- 原始系统建议、人工边界重算的规则建议、人工教练意见分别呈现。重算不等于教练赞同。
- 事件 P/R/F1 是当前人工参考的对照结果，模型辅助标注不能证明独立准确率。
- 地面单应性换算值显示为“几何换算估计”，不能凭地面标定宣称真实三维拍头速度。
- 人工评分是练习量表评价，标准仍待独立验证；不代表专业等级，不自动修改实时规则或训练模型。

## 数据与历史

`coach_review` 保存审核人、判断、可见事实、证据及建议；`practice_review` 保存五项 ratings 和 confirmed；`contact_review` 保存触球审核状态。服务端和前端都校验，非法审核不发布新版本。现有原子发布、不可变 revision、源帧身份校验保持。

历史会话显式升级：

```sh
venv_yolo26/bin/python scripts/upgrade_human_coach_review.py --session-dir /absolute/path/to/session
```

脚本在同级创建新审核副本，保留原会话全部文件；只重新计算已有事件审核，不代替教练确认触球或评分。复制的旧 evidence manifest 改为 source 前缀，避免声称它验证新页面；升级回执记录原文件与升级快照哈希。新副本首次打开暂停自动刷新。
