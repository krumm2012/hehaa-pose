## 指标契约

| 指标 | 公式、坐标与窗口 | 有效条件 / 限制 |
|---|---|---|
| 鞋底候选地面投影 | `H * [x,y,1]` 齐次除法；A 为原点，AB 为宽轴、AD 为长轴，单位米 | 已复核可见候选、实测尺寸、机位确认、源绑定及尺寸一致、位于标定地面内；不等于压力中心 |
| 足间距离 | 同帧同视角左右候选地面投影欧氏距离 | 两点均可映射；不填未知点、不融合视角 |
| 足部连线相对球道方向 | `atan2(abs(dx), abs(dy))`，与 AD 的无向夹角 0–90° | 两点不重合；交换左右不改变角度；不解释开放/关闭站姿 |
| 连续候选位置变化 | 同视角同名足、源帧 `f-1` 与 `f` 的投影距离 | 两点有效、同一 reported media_pts 时基、对应帧身份且时间严格递增；跨缺帧或未知点断开，不推导速度或真实支撑脚运动 |
| 跨视角差异 | 同源帧同名足投影距离，仅诊断 | 镜中对应未确认，不允许融合；选点位置/左右足/镜面几何也会造成差异 |
| 定位扰动场景 | 每点原图 x/y 各取 `-r,0,+r`，r=3/6 像素，映射后枚举组合 | 有限采样范围，不是误差界、置信区间或准确率；不含四角误差；扰动跨标定地面边界则缺失 |

候选位移是否超过 ±6px 扰动样本包络仅为敏感性提示。转脚、鞋底接地区域变化或身份错误，都可能使候选变化；不得据此确认真实支撑脚移动。标定没有独立实测检查点，背面对应尚未确认，全部评分/准确率资格保持 false。
