# 双视角比例、连续性与足部边界检查

新增离线脚本 `scripts/audit_pose_contact_consistency.py`，为现有66帧足部复核产生可疑帧/关节队列。Tennis Analyzer 实时推理、骨架原始数据和四角标定不修改。

## 观测资格与来源

校验原片和帧日志摘要，并逐帧顺序解码原片，与复核 PNG 逐像素比较。实际66帧全部一致。只使用原始 source pixel 双视角记录；关节点必须源帧一致、实际观测、非镜面补点、模型分数至少0.5。分数不是位置准确概率。缺失点留缺失；脚踝/膝不足则拒绝足部邻域检查。

## 检查规则

- 同帧比例：正面/背面的肩宽、髋宽、左右肩髋侧长、左右膝踝长度，使用各自合格原始点计算。与同一连续选帧段内±5帧邻居比较，至少5个有效邻居；对数比值偏离阈值取 `max(log(1.35), 4.5×1.4826×MAD)`。绝对比例没有预设“正确值”。
- 连续性：只比较相邻源帧；使用 reported media_pts，重复/无效时钟及小于局部中位间隔1/4的样本不判断跳变。移除髋中心的平移，以平均小腿像素长度归一化；同时超过0.45小腿长度和每秒6小腿长度时提示相对跳变。未做身体旋转补偿，真实挥拍也可能触发。
- 左右身份：比较同名连接代价与左右交换连接代价。交换成本低于原成本55%，且降低超过0.3小腿长度时提示，绝不自动交换原始点。
- 双点塌缩：左右肩/髋/踝距离低于0.08小腿长度时提示。重叠投影也可能造成真实近邻。
- 足部邻域：由同侧膝踝长度确定脚踝附近ROI；检查接地点是否在ROI内、是否远于0.6小腿长度、是否更接近另一侧脚踝。脚踝本身错位也会触发，不据此自动移接地点。
- 边缘：鞋附近ROI使用两组Canny阈值30/90、60/150；两组最近边缘距离都超过0.08小腿长度（或无边缘）才提示弱支持。报告显示边缘图。此为**候选图像边界检查，不是鞋语义分割**；地砖、衣物、前景人体都可产生边缘。强边缘永不自动证明鞋底接地。

阈值是尚未独立校准的复核启发式；不输出“准确率”或评分，不自动改四角或原始人体点。
