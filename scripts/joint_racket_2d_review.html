km/h几何估算：推导公式、实现分支与假设

这部分解释现有算法，不将假设换算升级为真实速度。设像素点pᵢ=(uᵢ,vᵢ,1)ᵀ；地面单应矩阵H映射到米制地面，π为齐次除法：

gᵢ = π(H pᵢ) = ((h₁·pᵢ)/(h₃·pᵢ), (h₂·pᵢ)/(h₃·pᵢ)) 相机中心 C=(Cₓ,Cᵧ,Hc)，离地高度 hᵢ 的物点 Qᵢ 位于从C到gᵢ的同一视线上。 Qᵢ(z) = Hc + λᵢ(0−Hc) = hᵢ ⇒ λᵢ = 1 − hᵢ/Hc qᵢ(x,y) = Cxy + (1−hᵢ/Hc)(gᵢ−Cxy) 理想三维平均速率 ≈ 3.6 × √(||q₁−q₀||²+(h₁−h₀)²) / Δt [km/h] 仅水平投影速率 = 3.6 × ||q₁−q₀|| / Δt

仅有地面H不能确定每帧离地高度或相机三维位置。现实现按脚踝与肩膀的图像垂直距离猜高度：

y_ground = max(y_left_ankle, y_right_ankle) y_shoulder = mean(available shoulder y) ĥ = clip(1.40 × (y_ground − y_racket)/(y_ground − y_shoulder), 0.15, 2.70) m body_span < 25px 或缺点 → 高度不可估；现实现可能继续走地面投影分支。 当前默认 Hc = 3.10m，无逐帧高度时 ĥ = 1.20m；逐帧高度优先。Cxy = (0,0)，前后两点使用同一个高度。 α = 1 当 ĥ≤0、ĥ≥Hc 或Hc≤0（退回地面） α = max(0.20,1−ĥ/Hc) 其他情况 q̂ᵢ = Cxy + α(gᵢ−Cxy) v̂_raw = 3.6 × ||q̂₁−q̂₀||/Δt = 3.6 × α||g₁−g₀||/Δt 先拒绝地面换算位移>4m 或速率>90m/s；剩余速率再限幅： v̂_out = 3.6 × min(v̂_raw/3.6, √(1050×1.20)) ≈ min(v̂_raw,127.8) km/h

可选2D姿态推断中的1.40m肩高、当前3.10m相机高、1.20m拍点高度及转动半径与1050m/s²限值均是代码假设，并非本次实测。前后点高度变化、透视、拍框中心偏移与极短PTS均可造成误差；ĥ≥相机高时退回地面还会产生分支变化。限幅结果不是可信峰值。本页主指标因此保留px/s，拒绝提供“真实km/h”。
